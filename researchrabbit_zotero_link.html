Review imported items

Zotero Connector Import:

Open ResearchRabbit in your browser
Navigate to your collection
Click Zotero Connector icon in browser toolbar
Select "Save to Zotero" for individual papers or use folder icon for multiple
Papers will be saved directly to your Zotero library

Import Configuration for Enzymatic Research:

Before importing, configure Zotero settings: 1. Go to Edit → Preferences → Advanced → Files and Folders 2. Enable: ✓ Automatically attach associated PDFs 3. Enable: ✓ Automatically rename attached files 4. Set naming convention: {%raw%}{%c}{%endraw%} - {%raw%}{%y}{%endraw%} - {%raw%}{%t}{%endraw%} 5. Go to Edit → Preferences → General 6. Set default collection: Epitope Erase Research

Post-Import Verification:

  1. Check item count: Verify all papers from ResearchRabbit are in Zotero
  2. Verify metadata: Check titles, authors, journals are complete
  3. Check DOIs: Ensure DOI field is populated (for automatic PDF fetching)
  4. PDF attachment: Zotero should automatically fetch PDFs for papers with DOIs
  5. Collection structure: Verify papers are in correct subcollections

⚠️ Common Import Issues

Missing PDFs: Zotero may not have access to all papers. Solutions:
1. Use institutional VPN/proxy
2. Manually download PDFs and drag into Zotero
3. Use browser extension to save PDFs directly
Duplicate papers: Zotero may create duplicates. Use Library → Find Duplicates to merge.
Incomplete metadata: Some fields may be missing. Right-click → "Retrieve Metadata" to fix.

Automated PDF Fetching:

To automatically fetch PDFs for imported papers:

  1. Select all imported papers (Ctrl+A)
  2. Right-click → "Find Available PDFs"
  3. Zotero will search for PDFs using DOIs and other identifiers
  4. This may take several minutes for large collections
  5. Review and attach any missing PDFs manually

Troubleshooting Common Issues:

❌ Export Fails

Solution: Try different browser, clear cache, or export smaller batches

❌ Import Fails in Zotero

Solution: Ensure file is .ris or .bib format, not corrupted

❌ Missing PDFs

Solution: Manually attach PDFs, check institutional access, use Sci-Hub as last resort

❌ Duplicate Papers

Solution: Use Zotero's "Find Duplicates" feature, merge manually

❌ Metadata Incomplete

Solution: Right-click → "Retrieve Metadata", manually edit missing fields

❌ Tags Not Preserved

Solution: ResearchRabbit may not export tags. Manually add in Zotero
