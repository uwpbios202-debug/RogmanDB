Install Zotero ARIA Plugin

Install the ARIA plugin into your Zotero installation. This guide assumes you've selected ARIA as your AI plugin.

[Image: Zotero Add-ons Manager Interface]

Visual showing Zotero Tools → Add-ons menu with "Install Add-on From File" option highlighted

Installation Method 1: From GitHub (Recommended)

  1. Download ARIA: Go to: https://github.com/vimagick/zotero-aria/releases
  2. Get Latest Release: Download the .xpi file from the latest release
  3. Open Zotero: Launch Zotero desktop application
  4. Install Plugin:
    • Go to Tools → Add-ons
    • Click the gear icon → Install Add-on From File...
    • Select the downloaded .xpi file
    • Restart Zotero when prompted

Installation Method 2: Manual Installation

  1. Clone Repository:
    git clone https://github.com/vimagick/zotero-aria.git
    cd zotero-aria
  2. Build Plugin:
    npm install
    npm run build
  3. Install in Zotero: Follow same steps as Method 1

Verification:

  1. After restarting Zotero, go to Tools → Add-ons
  2. Verify "Zotero ARIA" appears in your add-ons list
  3. Check that ARIA icon appears in Zotero toolbar
  4. Right-click on any paper in your library to see ARIA options

🔧 Alternative: Zotero GPT Plugin

If ARIA doesn't work, try the Zotero GPT plugin:
1. Visit: https://github.com/MuiseDestiny/zotero-gpt
2. Follow similar installation steps
3. Uses similar AI capabilities but different interface

Troubleshooting Installation:

  • Plugin not showing: Ensure you have Zotero 6+ (Zotero 7 recommended)
  • Installation failed: Try disabling other plugins temporarily
  • Permission errors: Run Zotero as administrator/root during installation
  • Outdated plugin: Check GitHub for newer versions or forks

Configure AI API Access

ARIA requires an AI API key to function. Configure it with OpenAI, Anthropic, or local models for enzymatic paper analysis.

API Options for Enzymatic Research:

Option 1: OpenAI API (Recommended)
  1. Create account at https://platform.openai.com
  2. Navigate to API Keys section
  3. Create new API key
  4. Copy the key (it only shows once!)
  5. Paste into ARIA settings in Zotero
Cost: ~$0.01-0.10 per paper analysis
Best for: High-quality summaries of complex enzymatic studies
Option 2: Anthropic Claude API
  1. Sign up at https://console.anthropic.com
  2. Generate API key
  3. Configure ARIA to use Claude model
Cost: Similar to OpenAI
Best for: Longer papers and detailed analysis
Option 3: Local Models (Free)
  1. Install Ollama: https://ollama.ai
  2. Pull a model: ollama pull llama2
  3. Configure ARIA to use local endpoint
  4. Set endpoint to http://localhost:11434
Note: Requires good GPU (8GB+ VRAM)
Best for: Privacy-conscious researchers

ARIA API Configuration Steps:

  1. In Zotero, go to Edit → Preferences
  2. Find "ARIA" or "AI Assistant" in preferences tabs
  3. Enter your API key in the appropriate field
  4. Select model: gpt-4-turbo (recommended for research papers)
  5. Set temperature: 0.3 (for more factual, less creative responses)
  6. Click "Test Connection" to verify API works

⚠️ API Key Security

1. Never commit API keys to version control (Git)
2. Use environment variables if possible
3. Set usage limits on your API account
4. Monitor usage regularly to avoid unexpected charges

Custom Prompts for Enzymatic Research:

Pre-configured Prompts for ARIA:
Prompt 1: Enzymatic Summary
Summarize this paper focusing on: 1) Enzyme type used (subtilisin, papain, etc.), 2) Surface material tested, 3) Allergen removal effectiveness, 4) Method validation techniques (ELISA, swabbing), 5) Key limitations mentioned. Format as bullet points.
Prompt 2: Method Extraction
Extract the experimental methods section focusing on: enzyme concentration, contact time, temperature, pH conditions, surface preparation, control experiments, and statistical analysis methods. Present in a structured table format.
Prompt 3: Gap Analysis
Analyze this paper to identify research gaps in enzymatic allergen removal. Focus on: 1) Unexplored enzyme combinations, 2) Missing surface materials, 3) Lack of long-term stability data, 4) Absence of cost analysis, 5) Unaddressed regulatory considerations. Suggest 3 follow-up experiments.
Prompt 4: Comparative Analysis
Compare these 3 papers on enzymatic cleaning. Create a comparison table with columns: Enzyme used, Concentration, Contact time, Surface type, Effectiveness %, Validation method, Cost implication, and Industrial feasibility.

ARIA Configuration Settings:

  1. Default Prompts: Add the enzymatic prompts above as defaults
  2. Output Location: Configure to save summaries as notes in Zotero
  3. Auto-tagging: Enable automatic tagging based on content analysis
  4. Batch Processing: Set up batch analysis for multiple papers
  5. Custom Instructions: Add: "Focus on enzymatic methods for allergen removal, particularly protease applications"

Workflow for Enzymatic Paper Analysis:

  1. Import: Save paper to Zotero using Connector
  2. Initial Scan: Right-click → ARIA → "Quick Summary"
  3. Detailed Analysis: If relevant, use "Detailed Enzymatic Analysis" prompt
  4. Data Extraction: Extract specific experimental parameters
  5. Note Generation: Save analysis as note in Zotero item
  6. Tagging: Apply tags based on enzyme type and methods
