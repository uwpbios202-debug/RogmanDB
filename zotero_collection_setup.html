Creating Collections in Zotero:

Step-by-step: 1. Right-click in the left panel → "New Collection" 2. Name: "Epitope Erase Research" 3. Right-click the new collection → "New Subcollection" 4. Create all subcollections following the structure above 5. Use drag-and-drop to organize hierarchy

Collection Descriptions (Optional but Recommended):

Add descriptions to each collection to document their purpose:

  • Subtilisin Applications: Papers specifically on subtilisin protease for allergen removal, including concentration studies, contact time optimization, and comparative effectiveness.
  • Sprayable Formulations: Studies on enzyme delivery systems, foam/spray applications, industrial implementation feasibility.
  • ELISA Protocols: Validation methods, detection limits, comparative studies of different ELISA kits for allergen detection.
  • FDA Guidelines: Regulatory documents, guidance papers, compliance requirements for enzymatic cleaning in food facilities.

🎯 Collection Strategy Tips

1. Start broad, then narrow: Begin with main categories, add specifics as your collection grows
2. One paper, multiple collections: Papers can appear in multiple collections (they're virtual copies)
3. Regular review: Monthly, review collections and adjust structure as needed
4. Balance depth vs. breadth: Avoid too many levels (max 3-4), but ensure meaningful organization
5. Future-proof: Create collections for planned research directions

Creating and Managing Tags in Zotero:

1. Open Zotero and go to your library 2. Click on the "Tags" tab in the right panel 3. Right-click in tags area → "Create New Tag" 4. Enter tag name (use lowercase_with_underscores) 5. Click on tag color to assign color coding 6. To apply tags to papers: select papers → right-click → "Add Tags"

Automatic Tagging Rules:

Configure Zotero to automatically apply tags based on criteria:

Automatic Tag Rule: "subtilisin"
Field: Title, Abstract, or Keywords
Condition: Contains "subtilisin"
Action: Add tag "subtilisin"
Automatic Tag Rule: "ELISA"
Field: Title, Abstract, or Keywords
Condition: Contains "ELISA" or "enzyme-linked immunosorbent assay"
Action: Add tag "ELISA_validation"

🏷️ Tagging Best Practices

1. Consistent naming: Use lowercase_with_underscores
2. Color coding: Use consistent colors (green for enzymes, blue for methods, etc.)
3. Apply multiple tags: Average 3-5 tags per paper
4. Review periodically: Monthly tag cleanup and consolidation
5. Document your system: Keep a master list of tags and their meanings

Create Smart Collections

Smart Collections automatically organize papers based on rules, saving you time and ensuring consistency.

Essential Smart Collections for Enzymatic Research:

🔥
High Priority Reading

Papers that are foundational to your research.

Tag: high_priority
OR Tag: review_paper
AND NOT Tag: already_read
🧪
Recent Methodology Papers

New methods and techniques for enzymatic cleaning.

Tag: methodology
Year: 2020-2025
Item Type: Journal Article
🏭
Industrial Application Focus

Papers with practical, large-scale applications.

Tag: industrial_scale
OR Abstract contains: "factory" or "plant" or "industrial"
NOT Tag: laboratory_only
💸
Cost-Benefit Analysis

Papers discussing economic aspects.

Tag: cost_analysis
OR Abstract contains: "cost" or "economic" or "feasibility"
NOT Tag: theoretical
📊
Validation Methods Collection

All papers on validation and detection methods.

Tag: ELISA_validation
OR Tag: swabbing
OR Abstract contains: "validation" or "detection limit"
🚀
Sprayable Formulations

Papers on delivery systems and formulations.

Tag: sprayable
OR Title contains: "spray" or "foam" or "formulation"
AND Tag: protease

Creating Smart Collections in Zotero:

Step-by-step: 1. Right-click on your library → "New Smart Collection" 2. Name: e.g., "High Priority Reading" 3. Click "+" to add conditions 4. Configure rules (see examples above) 5. Choose match: "any" (OR) or "all" (AND) 6. Click "OK" to create Smart Collections update automatically as you add/remove papers!

Advanced Smart Collection Examples:

Smart Collection: "Recent Subtilisin Studies"
Condition 1: Tag contains "subtilisin"
Condition 2: Year is after 2018
Condition 3: Item Type is "Journal Article"
Match: ALL conditions
Smart Collection: "To Read - Enzymatic Methods"
Condition 1: Tag is "to_read"
Condition 2: Collection is "Enzymatic Methods" or any subcollection
Match: ALL conditions

🚀 Advanced Smart Collection Strategies

1. Nested Smart Collections: Create Smart Collections based on other Smart Collections
2. Temporal Collections: "Added in Last 30 Days" for staying current
3. Priority Collections: Combine multiple tags for priority filtering
4. Export-Ready Collections: Smart Collections for specific outputs (grants, papers, presentations)
5. Collaboration Collections: Smart Collections showing papers relevant to specific collaborators

Maintenance Schedule for Smart Collections:

  • Weekly: Review "To Read" collections
  • Monthly: Update date-based rules (e.g., "Recent" should move forward)
  • Quarterly: Review and optimize all Smart Collection rules
  • Annually: Archive old Smart Collections, create new ones for new directions

Creating and Using Note Templates in Zotero:

Step-by-step note creation: 1. Select a paper in your library 2. Click the "Notes" tab in the right panel 3. Click "Add" to create a new note 4. Paste your chosen template 5. Fill in the template with paper-specific information 6. Save the note (auto-saves as you type) Pro tip: Create a "Templates" collection in Zotero with these templates as notes for easy copying!

Advanced Note Features:

Note Linking and Connections
Link Papers: Drag one paper onto another in Zotero to create "Related" links
Note-to-Note Links: Use Zotero's internal linking: zotero://select/items/[itemKey]
Tag Notes: Add tags to notes themselves for organization

Note Organization Strategy:

  • Standardized Structure: Use consistent templates for comparable analysis
  • Keyword Rich: Include key terms for searching
  • Date Stamped: Always include analysis date
  • Action Oriented: Include "next steps" or "research connections"
  • Regular Review: Monthly review of notes to identify patterns

📝 Note-Taking Workflow

1. First Pass (5 min): Skim paper, add to "Epitope Erase Research" collection
2. Second Pass (15 min): Read abstract/introduction/conclusion, apply initial tags
3. Deep Analysis (30-60 min): Use template for detailed analysis
4. Synthesis (Monthly): Review all notes on a topic, create comparative analysis
5. Extraction (As needed): Pull data from notes for writing proposals/papers
