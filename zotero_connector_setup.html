Install Zotero Connector for Your Browser

The Zotero Connector is a browser extension that detects scholarly content and saves it to your Zotero library with one click. It works with 100+ academic databases and websites.

⚠️ Prerequisite Check

Ensure Zotero Standalone is installed and running before proceeding. The Connector needs the desktop app to function properly.

Choose Your Browser:

🌐
Google Chrome

Most popular browser with full Zotero support

🦊
Mozilla Firefox

Open-source browser with excellent Zotero integration

🚀
Microsoft Edge

Chromium-based with full Chrome extension support

🍎
Safari

macOS native browser with Zotero support

Chrome Installation Steps:

  1. Open Chrome and go to: https://chrome.google.com/webstore/detail/zotero-connector/ekhagklcjbdpajgpjgmbionohlpdbjgc
  2. Click "Add to Chrome" button
  3. Confirm by clicking "Add extension" in the pop-up
  4. Wait for installation to complete
  5. You should see the Zotero Connector icon (Z) in your browser toolbar

Firefox Installation Steps:

  1. Open Firefox and go to: https://www.zotero.org/download/connector?format=firefox
  2. Click "Add to Firefox" button
  3. Confirm by clicking "Add" in the pop-up
  4. Wait for installation to complete
  5. You should see the Zotero Connector icon (Z) in your browser toolbar

Edge Installation Steps:

  1. Open Edge and go to: https://microsoftedge.microsoft.com/addons/detail/zotero-connector/dfgmbgppnmhlicfkodjggjogljhdhdgb
  2. Click "Get" button
  3. Confirm by clicking "Add extension" in the pop-up
  4. Wait for installation to complete
  5. You should see the Zotero Connector icon (Z) in your browser toolbar

Safari Installation Steps:

  1. Open Safari and go to: https://apps.apple.com/app/zotero-connector/id1516140339
  2. Click "Get" button
  3. Download and install from the Mac App Store
  4. Enable the extension in Safari Preferences → Extensions
  5. You should see the Zotero Connector icon (Z) in your Safari toolbar

🎯 Installation Verification

After installation, you should see a Zotero icon (Z) in your browser toolbar. If not, check your browser's extension management page and ensure it's enabled.

Configure Connector for Enzymatic Research

Proper configuration ensures papers are automatically tagged and saved to the correct collections for your enzymatic allergen research.

[Image: Zotero Connector settings interface]

Visual showing Zotero Connector options with default collection and tags highlighted

Access Connector Settings:

  1. Click the Zotero icon (Z) in your browser toolbar
  2. Click the gear/settings icon in the pop-up menu
  3. Select "Preferences"

Essential Configuration Settings:

📁
Default Collection

Set to: Epitope Erase Research

All saved papers will automatically go to this collection

🏷️
Automatic Tags

Add tags: enzymatic_cleaning, protease, saved_from_web

These tags will be added to every paper you save

📄
PDF Handling

Settings: Save PDFs automatically when available

Attach PDFs to saved references automatically

🔍
Snapshot Feature

Enable: Save webpage snapshots

Creates local copies of webpages for offline access

Advanced Configuration:

  1. Library Selection: Ensure your "Epitope Erase Research" library is selected
  2. Automatic Categorization: Enable automatic detection of paper type (journal article, conference paper, etc.)
  3. Proxy Settings: If accessing papers through institutional proxy, configure proxy settings for full-text access
  4. Keyboard Shortcuts: Set up shortcuts for quick saving (e.g., Alt+Z)

⚙️ Database-Specific Configuration

Some databases need special configuration:
1. PubMed: Enable RIS export compatibility
2. Google Scholar: Configure library links in Google Scholar settings
3. IEEE Xplore: Enable RIS/Citation export
4. ScienceDirect: Works best with institutional access

Test & Optimize Your Setup

Test your Zotero Connector with actual research papers to ensure everything works correctly for your enzymatic allergen studies.

🧪 Test Procedure

Follow these steps to test your Zotero Connector:

Test 1: Basic Saving
  1. Visit this test article: https://pubmed.ncbi.nlm.nih.gov/30003958/
  2. Click the Zotero icon (Z) in your toolbar
  3. Observe the icon change to indicate detection
  4. Click to save the reference
  5. Check Zotero desktop app for the saved paper
Test 2: Enzymatic Research Paper
  1. Search for: "subtilisin allergen removal surface" in Google Scholar
  2. Find a relevant paper and click the Zotero icon
  3. Verify PDF is attached (if available)
  4. Check that tags "enzymatic_cleaning" and "protease" are applied
  5. Confirm paper is in "Epitope Erase Research" collection
Test 3: Multiple Items
  1. Visit a search results page (e.g., PubMed search results)
  2. Click the folder icon in the Zotero Connector
  3. Select multiple papers to save at once
  4. Verify all are saved with correct metadata

Expected Results:

✅ Success Indicators

1. Paper appears in Zotero within 5 seconds
2. Metadata (author, title, journal) is complete
3. PDF is attached (if available through your access)
4. Tags are applied correctly
5. Paper is in the correct collection

Troubleshooting Common Issues:

❓
Icon Not Appearing

Solution: Refresh page, check if Zotero desktop is running

📄
PDF Not Attaching

Solution: Check institutional access, try manual PDF save

🏷️
Tags Not Applied

Solution: Recheck Connector settings, restart browser

⚡
Slow Saving

Solution: Check internet connection, reduce Zotero library size

🔧 Optimization Tips

1. Keyboard Shortcuts: Set Alt+Z for quick saving
2. Right-click Menu: Enable "Save to Zotero" in browser context menu
3. Multiple Selection: Use folder icon on search result pages
4. Automation: Create rules for auto-tagging specific journals

Advanced Features & Workflow Integration

Leverage advanced Zotero Connector features to streamline your enzymatic research workflow.

1. ResearchRabbit Integration:

  1. Install both Zotero Connector and ResearchRabbit
  2. In ResearchRabbit, export papers directly to Zotero
  3. Use Zotero Connector to save additional papers found through ResearchRabbit recommendations
  4. Create a seamless workflow: ResearchRabbit → Zotero Connector → Zotero Library
